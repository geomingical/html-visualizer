# 教學型伴讀：沿著時間，保留理解如何形成

適用於把**已有的課程、教學影片、講座、逐字稿或連續教材**做成閱讀頁。若使用者只問「解釋某個概念」，沿用 explainer 骨架 A。使用者明確要重點摘要時可摘要，但要標明範圍，不稱為完整伴讀。

這是一種內容整理模式，共用原 skill 的樣式、評論、來源與互動能力，不規定另一套品牌或框架。在 `<head>` 放入：

```html
<meta name="html-visualizer-mode" content="teaching-companion">
```

`verify.py` 會據此保留通用檢查，停止強迫每節配圖或收合深入內容；此標記**不證明內容完整**。

## 先決定在保留什麼

- **完整概念筆記**：預設用於教學伴讀。可整理口語與分段，但保留各階段的問題、前提、解釋、例子、推演、失敗與修正、限制、後續回扣。不是把章節名稱列完就算完整。
- **全文伴讀**：使用者要求全文保留或已接受這種版本時，正文保留全部來源內文；導讀、銜接、校正另標。以逐節文字比對驗證，事先說明只容許哪些差異，例如空白與段落重排。
- **選段／摘要**：只處理指定片段或重點時，在開頭標明範圍與省略內容，不用完整課程的名義交付。

長度不構成自行改成摘要的理由。三小時課程可能需要長筆記；用目錄、小節、搜尋與閱讀位置解決查找成本。也不要反過來把一次全文試作變成所有教學都必須逐字保留。

## 來源與時間先對齊

1. 讀實際來源的標題、開頭、結尾與段落清單；同一位講者的不同影片要分開確認。檔名、同資料夾與使用者估計的時長都不能單獨確定影片身分。
2. 記錄來源檔、影片標題／網址、可驗證的時長、版本或整理日期。需要時間連結時，核對影片或原章節表。
3. 在工作檔建立「來源單元 → 筆記段落 → 影片入口／PDF 頁」對照。原素材沒有時間碼，就保留來源順序並說明未對時；不可按文字長度平均分配時間或捏造精確秒數。
4. 章節入口、截圖擷取時間與逐句對時是不同精度。章節表只支持主題入口，不能宣稱每小節逐句同步；PDF 頁碼也不能當作影片時間。

## 以教學順序為主線

保留實際的「為什麼先講這個 → 怎麼推到下一步 → 何時回頭修正」。時間軸只是入口，重點是理解上的依賴關係。

- 開場的動機、學習前提與問題意識是正文，不只剩一張結論卡。
- 例子保留必要的題目、輸入、步驟、結果及解釋。失敗示範與後續修正不可只剩修正後的答案；沒有完整輸入就標明缺漏，不補造條件。
- 同一概念後來再出現時保留該位置，用回扣連結指出與前文的關係。不要為了去重而刪掉教學上必要的重訪。
- 可以合併相鄰的小節成章，但保留章內原順序與足夠小標。不要先依術語分類，導致後面的知識被搬到前面當成已知。
- 重要原理、推導與邊界若是當段理解必需，直接展開。折疊僅用於可選的延伸資料、重複來源與非必要細節；不為通過版型檢查而折疊正文。
- 導讀與銜接只補方向，不替代內文。旁註區分來源敘述、辨識疑點、整理者解釋與外部補充。全文模式不靜默改原文；疑點在旁說明。

可用的章節節奏是「短導讀 → 依原順序分節的內文 → 當地需要的圖／例子／提醒 → 一句承接」。這不是每章必填的卡片數量。

## 圖片要幫助理解當下的概念

優先考慮實際操作介面、關鍵圖表、模型結構、例子前後狀態與重要板書。沒有圖也能清楚理解的段落可以純文字，不設定每章一圖或固定張數。

- 原影片／PDF 畫面附來源與擷取時間／頁碼，中文圖說說明「看哪裡、和本段概念有什麼關係」。整理者重畫的圖標成示意，不冒充原截圖。
- 擷取時聚焦教學區域，可裁掉人物視窗、工具列、無關邊緣；不得裁掉必要的座標軸、圖例、前提或結果。保留比例，不用生成式補畫冒充證據。
- 預設圖片適度縮小，外層圖框與正文對齊，內圖可置中；例如桌面高約 280–320 px 起試，實際看字是否讀得清楚，不把數值當硬門檻。細節多時提供點圖放大。
- 指定圖片寬高或比例，延遲載入前保留空間，避免正在閱讀的長文跳動。手機放大後可在圖片框內捲動；整頁不得橫向溢出。關閉、Escape、焦點返回原圖片皆須可用。
- 截圖只證明當時畫面。產品介面、示例結果、模型能力與排行榜保留來源的時間背景，不把舊示例寫成現在所有模型的定論。

## 交付前，分開驗證三件事

**來源覆蓋**：逐一走過來源單元對照表，核對是否跳過動機、推演、例子、失敗或回扣；抽查開頭、中間、結尾與合併邊界。若宣稱全文，對每節正文做實際內容比對，不只比較標題或數量。若是完整概念筆記，比對理解鏈條而非要求逐字相同。明列省略、待核或未取得的部分。

**來源準確**：檢查數字、單位、算式、專名、圖文對應與時間精度。區分「全部收錄」與「逐字正確」，不把結構檢查當成事實查核或學習成效證據。

**閱讀行為**：桌面、窄螢幕實看正文、圖框、圖說的共同邊界與字級；點目錄、搜尋、時間連結、放大及關閉。長筆記若提供閱讀位置、評論或匯出，確認保留原閱讀流程。圖片能載入並不代表裁圖與圖說正確，必須看實際圖像。

## 從試作搬到既有網站

使用已接受版本，不重做一份摘要。先找出真正 Git 根目錄及現有入口，保留網址與返回書庫的路徑；調整相對圖片／來源連結，移除只在本機成立的試作入口。只搬需要的頁面與資源，擷取原檔、QA 截圖、草稿與本機路徑不自動公開。

先在本機完成替換與驗證。發布範圍及 Git 操作依當次授權；不得因來源資料夾附近有 repo，就把整個資料夾全部加入。
